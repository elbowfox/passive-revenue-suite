# Content Automation Bot (Telegram / Discord)

Skeleton for a bot that generates and schedules content.

## Features

- Accept a topic or URL
- Generate multi-platform posts
- Optional scheduling
- User subscription check (via Stripe webhook or simple DB)

## Deployment

- Host on Railway.app or Render
- Use Telegram Bot API or Discord.js
- Store user plans in Supabase or SQLite

## Revenue

- Free: 5 generations/day
- Pro: $9/mo unlimited
