## Quick Start

1. **Web App**: Deploy `web-app/` to Vercel (free tier for testing; Pro for commercial).
2. **Chrome Extension**: Load unpacked in `chrome://extensions` or publish to Chrome Web Store.
3. **Digital Products**: List on Gumroad, Payhip, or Etsy.
4. **Bots**: Host on Railway, Render, or Fly.io.

## Monetization Stack

- **Payments**: Stripe, Lemon Squeezy, or Gumroad
- **Hosting**: Vercel / Netlify (web), Railway (bots)
- **Analytics**: Plausible or PostHog
- **Email**: Beehiiv or ConvertKit for list building
- **AI**: OpenAI / Anthropic / xAI API (user-provided keys for cost control)
